Foundations and Applications of Low-Rank Approximations

Low-rank approximation is now ubiquitous in scientific and machine learning fields to deal with large-scale problems and high-dimensional data. It represents a high-diemnsional object with multiple low-diemnsional structures. This course covers popular aproaches to compute low-rank approximations of matrices and tensors, and current research in this area. The course aims to cover the following topics.

  • Matrix factorizations
  • SVD, QR based low-rank approximations
  • Randomized low-rank approximations
  • Hierarchical matrices
  • Introduction to tensors
  • CP, Tucker and Tensor-train decompositions
  • Applications of low-rank approximation in scientific computations and machine learning
  • Other popular topics

Prerequisite

Experience with Python or a similar language is expected. Prior knowledge of linear algebra is helpful but not required.

Evaluation

The evaluation will be based on the following weightings:
  • 5 small assignments (50% weight)
  • Project (50% weight): Each student will select a topic based on their interests and work on it. The output will be assessed based on a written report and an oral presentation.
